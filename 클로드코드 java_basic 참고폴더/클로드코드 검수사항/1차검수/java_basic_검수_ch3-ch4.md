## ch3_연산자

### 기술적 오류 / 잘못된 주석
- [중간] `java_basic/java_class_ch3_연산자/src/P1부호증감대입.java:22-24` — 주석이 부정확하고 자기모순. "후위연산자는 임시변수 생성 => 메모리 낭비"는 JIT 최적화로 실질 차이가 없는 오개념이며, 낭비라고 해놓고 바로 "후위연산자 사용하세요"라고 권장해 논리가 모순됨. "왠만하면"도 오타(→ 웬만하면). 주석 전체를 "값을 사용하는 시점 차이"만 설명하도록 정리 권장.
- [중간] `java_basic/java_class_ch3_연산자/src/P5NanInfinity인데굳이하지말자.java:6` — `System.out.println(3/0.0); //int 0으로 나누면 에러` 주석이 해당 줄 동작과 반대. `3/0.0`은 double 나눗셈이라 `Infinity`가 출력되고 에러가 아님. "int를 int 0으로 나누면(3/0) ArithmeticException" 취지의 별도 줄/주석으로 분리 필요.
- [낮음] `docs/java_basic/ch3_연산자.md:108` — `a == 0.3 // false 가능` 표현이 모호. Java에서 `0.1 + 0.2 == 0.3`은 항상 false이므로 "false 가능"이 아니라 "false"로 단정하는 것이 정확.

### 문서-코드 불일치
- [중간] `docs/java_basic/ch3_연산자.md:376-378`(문제 D1) vs `src/quest/Q3.java:11-13` — 문제는 `<< 1`, `>> 1`, `>>> 1` 세 결과를 요구하는데 Q3에는 `>>> 1` 출력이 누락됨.
- [중간] `docs/java_basic/ch3_연산자.md:342-424`(문제 A~G) vs `src/quest/` — quest 코드가 A1(Q1), A2(Q2), D1 일부(Q3), A4(Q4) 4개뿐. A3(짝수/홀수)은 엉뚱하게 **ch4 quest Q1**에 들어가 있음(챕터 배치 오류). B~G 문제 대부분은 대응 코드가 없어 어느 문제까지 quest로 제출하는지 기준이 불명확.
- [낮음] `src/P7비트논리이동연산.java:1-7` — 문서 7~8장(비트/시프트)은 이미지까지 갖춰 상세히 설명하는데, 대응 소스 파일은 주석만 있는 빈 파일. 문서 예제 코드라도 채워 넣기 권장.

### 초보자 관점 / 순서 문제
- [중간] `docs/java_basic/ch3_연산자.md:398-409`(문제 F) — 디버깅 문제에 `for` 반복문이 등장하는데 for문은 ch4에서 처음 배움. 문제를 ch4로 이동하거나 반복문 없는 형태로 수정 필요.
- [중간] `docs/java_basic/ch3_연산자.md:133-142, 164-176` — `new String(...)`, 참조 동일성, `obj.isValid()`, null 등 객체 개념(ch6)과 "NPE" 약어가 설명 없이 등장. 최소한 "NullPointerException, 자세한 내용은 ch6" 같은 안내 필요.
- [낮음] `docs/java_basic/ch3_연산자.md:369, 379, 422-423`(문제 C2, D2, G2~3) — "함수/메서드를 작성/구현하시오"는 메서드를 배우기 전(ch6) 단계와 맞지 않음. "main 안에서 코드로 작성" 등으로 완화 권장.
- [낮음] 이미지 보완 제안 — 2.3 오버플로우(wrap-around 원형 다이어그램), 3.1 전위/후위 평가 순서, 5장 `==` vs `equals`(스택/힙 참조 그림)는 글로만 설명되어 다이어그램 보완 효과가 큼.

## ch4_제어문과반복문

### 기술적 오류 / 잘못된 주석
- [높음] `java_basic/java_class_ch4_제어문과반복문/src/P2switch문2.java:8` — 주석 `// switch변수에는 타입 뭐가 오든 상관없음`은 명백한 오류. switch는 byte/short/char/int(및 래퍼), String, enum만 허용하고 long, float, double, boolean은 컴파일 오류. 초보자가 그대로 믿기 쉬운 잘못된 규칙이므로 반드시 수정 필요.
- [낮음] `src/P1if문.java:7` — `score>=90` 분기 출력이 "점수가 90보다 큽니다"인데 90점도 포함되므로 "90 이상입니다"가 정확.
- [낮음] `src/P2switch문2.java:18-19` — `case "해린"`의 출력이 "다니엘"로 되어 있음(복붙 실수로 추정).

### 문서-코드 불일치
- [중간] `src/quest/Q1.java` — 짝수/홀수 판별은 ch4 문제 목록에 없음(ch3 문제 A3에 해당). ch4 A1(양수/음수/0 판별)에 대응하는 quest 코드는 없음. Q1을 A1 문제로 교체하거나 ch3 quest로 이동 필요.
- [중간] `docs/java_basic/ch4_제어문과반복문.md:167-178, 357`(5.2 do-while + 문제 D2) vs `src/P4While문.java:3-4` — 문서는 do-while을 정식으로 가르치고 문제까지 내는데, 소스에는 do-while 예제가 전혀 없고 주석으로 "본 적이 있나 싶음"이라며 폄하함. 자료 간 메시지 충돌 — 최소 1개 do-while 실행 예제 추가 권장.
- [중간] `docs/java_basic/ch4_제어문과반복문.md:143-150`(4.2 for-each) vs `src/P3향상된for문.java:1-6` — 문서는 for-each를 ch4에서 설명하는데 소스 파일은 "배열할 때 나옴" 주석만 있는 빈 파일. 진도 기준 불일치.
- [낮음] `docs/java_basic/ch4_제어문과반복문.md:207-218`(6.3 라벨 break) — 대응 소스 예제 없음. 문제 E3(label break)도 요구하므로 예제 추가 권장. 소스 번호가 P5 다음 P6 없이 P7예제로 건너뜀.

### 초보자 관점 / 순서 문제
- [중간] `docs/java_basic/ch4_제어문과반복문.md:365, 375, 384, 393-401`(문제 E1, F2, G1, H) — 배열(`int[]`, 2차원 배열, `arr.length`)을 광범위하게 사용하지만 배열은 ch5에서 학습. ch5 이후 복습용으로 표시하거나 배열 없는 버전으로 조정 필요. G2(사용자 목록 순회)도 객체/컬렉션 전제라 동일 문제.
- [낮음] `docs/java_basic/ch4_제어문과반복문.md:182-218` — break vs continue 차이가 글/코드로만 설명됨. 흐름 차이(루프 탈출 vs 회차 건너뛰기)와 label break를 시각화한 다이어그램 추가 권장.
- [낮음] `src/P3for문.java:12` — `for(...; sum+=i,i++)` 콤마 증감식은 유효하지만 입문 예제로는 트릭성. 표준형을 기본으로, 이 형태는 "참고"로 표시 권장.

### quest / 예제 품질
- [낮음] `src/quest/Q2.java:12-18` — 문서 B4는 "switch expression으로 리팩터링"인데 Q2는 각 분기에서 대입하는 화살표 switch 문. 값을 반환하는 `String season = switch (month) {...};` 형태가 모범답안으로 더 정확.
- [낮음] `src/P7예제.java:17-34` — switch에 default가 없어 1~4 외 입력이 조용히 무시됨. 출금 시 잔고 부족 검증 없음, print/println 프롬프트 스타일 불일치, 정수 외 입력 시 InputMismatchException 종료 언급 필요.
- [낮음] `src/quest/Q4.java:9` — 문서 D1은 "`while`(조건식) 사용"을 명시하는데 `while(true)+break` 패턴 사용. 문제 의도와 다르므로 주석으로 대안 표기 권장.
