## 1. ch2_변수와자료형.md 전면 재작성 (283줄 → 474줄)

기존 문서는 "이미 아는 사람용 요약"에 가까웠음 (개념 정의 없이 항목 나열).
ch3/ch4와 같은 서술형 톤으로 다시 썼고, **기존 문제/체크리스트는 그대로 유지**.
