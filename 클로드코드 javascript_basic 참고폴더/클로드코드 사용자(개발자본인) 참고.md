    🤖 세션 종료 전 프롬프트:
    "지금까지 분석/작업한 내용을 바탕으로, 
    **다음 단계 작업자가 이어서 코딩할 수 있도록 '
    작업 인수인계서(Handover Document)'**를 Markdown으로 작성해줘.
    여기에는 
    1) 현재까지의 진척 상황, 
    2) 다음 세션에서 반드시 고쳐야 할 파일 목록과 핵심 로직, 
    3) 주의해야 할 사이드 이펙트나 제약사항만 압축해서 포함해줘."
    
    이 때 폴더에  ~~작업.md 이런식으로 정확하게.     번호도 지정
