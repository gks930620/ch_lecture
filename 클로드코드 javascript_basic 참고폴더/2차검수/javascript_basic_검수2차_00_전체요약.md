## 즉시 수정 필요 (높음)

| # | 위치 | 문제 | 성격 |
|---|------|------|------|
| 1 | ch7 `part02_선택자와DOM조작.html:516, 528` | 1차에서 placeholder→인라인 SVG로 바꾼 `'src': 'data:image/svg+xml,...xmlns='http://...''` 가 **작은따옴표 중첩**으로 문자열 조기 종료 → `SyntaxError: Unexpected identifier 'http'`. `$(function(){...})` 전체가 로드 실패해 **이 페이지의 모든 데모 버튼(필터/text/html/val/append/remove/attr)이 동작 불가** | **1차 수정이 낳은 회귀** |

### 수정 방법 (#1)
`src` 값을 감싸는 **바깥 따옴표를 큰따옴표로** 바꾸면 내부 SVG의 작은따옴표와 충돌하지 않습니다.

```js
// before (516, 528) — 바깥·안쪽 모두 작은따옴표 → 조기 종료
'src': 'data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20...',
// after — 바깥을 큰따옴표로
'src': "data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20...",
```

(대안: 내부 작은따옴표를 `%27`로 URL 인코딩. line 414의 정적 `<img src="...">`는 HTML 속성이라 바깥이 큰따옴표 → 정상, 손댈 필요 없음.)
