## 전체 상태 한눈에 보기

- **기술 설명**: 대체로 정확함. ch3(JS기초)·ch5(DOM)·ch8(HTTP)·ch9(브라우저)은 핵심 개념이 정확하고 높음 등급 사실오류 없음.
- **이미지 링크**: 문서가 참조하는 이미지는 ch1 SVG 4종이 유일하며 모두 실재(깨진 링크 없음). 나머지 챕터는 이미지 참조 자체가 없고 ASCII 다이어그램으로 대체 → 입문자용 그림 보강 여지.
- **가장 큰 구조적 문제**: ① 거의 모든 챕터에서 강의노트가 실습 소스 파일을 한 번도 참조하지 않아 연결 단절. ② 소스 HTML 제목에 타 커리큘럼 장번호 잔재(26.x/27.x/28.x/32.x). ③ 문서(docs) 트리와 소스(javascript_basic) 트리가 이원화되어 완성현황·ch1에서 파일 위치/이름 불일치.

## 공통(챕터 횡단) 문제

1. **문서 ↔ 실습 소스 연결 부재**: 강의노트가 소스 파일명을 참조하지 않음. 각 절에 "실습: partXX_…html" 경로 표기 권장.
2. **소스 제목의 장번호 잔재**: ch1(26.x), ch2(27.x), ch3(28.x), ch7(32.x)이 화면 H1에 노출. 강의노트 번호(1~10장)와 불일치 → 타 커리큘럼에서 복사한 흔적. 일괄 정정 필요.
3. **문서↔소스 커버리지 어긋남**: ch3 소스가 노트에 없는 고차함수·IIFE·구조분해를 앞서 다룸, ch5 강의노트 종합예제가 실제 소스와 선택자·구조 상이, ch7 강의노트가 part03(이벤트/AJAX)을 통째로 안 다룸.
4. **이원화된 폴더 구조**: `docs/javascript_basic/`(문서+ch1 HTML) vs `javascript_basic/`(소스 HTML 30개). 완성현황(30개 파일)이 docs 기준으론 ch1만 실존해 과대 기술. ch1은 두 세트가 파일명까지 갈림 → 배포 기준 세트 확정 필요.
5. **코드펜스/템플릿 잔재**: ch4 part01~05, ch5 part01~02의 `</html>` 뒤에 마크다운 ` ``` ` 잔재. 일부는 브라우저에 문자로 노출됨(ch5).
6. **깨진 내부 링크**: PART3_웹기초.md의 이전/다음 링크(PART2/PART4)가 존재하지 않는 파일 지정.
7. **선수지식 안내 부족**: ch10 프로젝트 난이도 밴드가 실제 필요 기술(5장 DOM, 8장 LocalStorage)보다 낮게 표기. ch1 소스가 아직 안 배운 JS(onclick/alert)를 예고 없이 사용.
8. **이미지 보완 후보**(입문자용 "글로만 된 설명은 그림으로" 방침): ch2 specificity·자손vs자식, ch4 스코프체인·클로저·this바인딩·프로토타입체인, ch6 이벤트루프+마이크로태스크·실행순서, ch8 HTTP 요청/응답 구조·CORS Preflight 흐름, ch9 렌더링 파이프라인.
