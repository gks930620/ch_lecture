## 🔴 [1] 문서 참조 이미지 8개가 전부 깨짐 — 경로 누락

**심각도: 높음 (가장 시급)**

### 현상
- `docs/spring_ssr_security_oauth2/security oauth2 설명.md`
- `docs/spring_ssr_security_oauth2/security oauth2 설명_back.md`

두 문서가 아래처럼 **`seucirty 이미지/img*.png`** 를 참조합니다 (총 8장, img.png ~ img_7.png).

```markdown
![로그인 버튼 클릭](seucirty%20이미지/img.png)
![카카오 인증 서버로 요청](seucirty%20이미지/img_1.png)
...
```

그런데 실제 이미지 파일은 **문서 폴더가 아니라 소스 프로젝트 쪽**에만 있습니다.

```
있음: spring_ssr_security_oauth2/설계/seucirty 이미지/img*.png   (8장)
없음: docs/spring_ssr_security_oauth2/seucirty 이미지/            ← 폴더 자체가 없음
```

### 영향
OAuth2 로그인은 "브라우저 redirect → 카카오 → 인가코드 → 토큰 → 유저정보 → 세션" 흐름이라 **그림 없이는 초심자가 이해하기 매우 어렵습니다.** 문서가 그림에 크게 의존하는데 렌더링하면 8장 전부 깨진 이미지로 나옵니다. 강의 자료로서 치명적입니다.

### 조치 방안 (택1)
1. **(권장)** `spring_ssr_security_oauth2/설계/seucirty 이미지/` 8장을 `docs/spring_ssr_security_oauth2/seucirty 이미지/`로 복사.
   - 다른 java_basic 문서들은 이미지를 `java_basic_images/chN/`처럼 docs 하위로 옮겨둔 최근 커밋 패턴이 있으므로, 같은 방식으로 docs 하위에 두는 것이 일관적입니다.
2. 또는 문서의 이미지 경로를 소스 폴더 상대경로로 수정 (문서/소스가 함께 배포될 때만 유효 — 권장 안 함).

> ※ 폴더명 `seucirty`(오타, security 아님)는 소스와 문서가 동일하게 쓰고 있어 **경로만 맞추면 동작**합니다. 정리 차원에서 `security 이미지`로 바꾸려면 문서 참조 경로도 함께 바꿔야 합니다.

## 🟠 [2] index.html — 마크업 깨짐 (고아 `<p>` + 잉여 `</div>`)

**심각도: 중간**
**파일**: `spring_ssr_security_oauth2/src/main/resources/templates/index.html` (99~102행)

### 현상
4번째 feature-card(`권한 기반 접근 제어`)가 99행에서 정상적으로 닫힌 뒤,
**카드 밖에 고아 `<p>` 한 줄과 짝 없는 `</div>`가 남아 있습니다.**

```html
95                <div class="feature-card">
96                    <div class="feature-icon"><span class="material-icons">admin_panel_settings</span></div>
97                    <h3 class="feature-title">권한 기반 접근 제어</h3>
98                    <p class="feature-desc">USER/ADMIN 권한 분리, URL별 접근 제한, 관리자 페이지</p>
99                </div>
100                   <p class="feature-desc">Spring Security 세션 기반 로그인/로그아웃, BCrypt 암호화</p>  ← 고아(카드 밖)
101               </div>                                                                                    ← feature-grid 닫힘
102           </div>                                                                                        ← 짝 없는 잉여 </div>
103       </section>
```

### 영향
- 홈 화면 feature 그리드 **하단에 "Spring Security 세션 기반 로그인/로그아웃, BCrypt 암호화" 텍스트가 카드 바깥에 중복 노출**됩니다 (1번 카드 설명과 동일 문구가 복붙된 흔적).
- `<div>` 태그 균형이 깨져 있어(잉여 닫힘 1개) 브라우저가 관용적으로 렌더하긴 하나 마크업 오류입니다.

### 조치 방안
100~102행의 고아 `<p>`와 잉여 `</div>` 한 개를 제거하여 아래처럼 정리:

```html
                <div class="feature-card">
                    <div class="feature-icon"><span class="material-icons">admin_panel_settings</span></div>
                    <h3 class="feature-title">권한 기반 접근 제어</h3>
                    <p class="feature-desc">USER/ADMIN 권한 분리, URL별 접근 제한, 관리자 페이지</p>
                </div>
            </div>   <!-- feature-grid -->
        </section>
```
