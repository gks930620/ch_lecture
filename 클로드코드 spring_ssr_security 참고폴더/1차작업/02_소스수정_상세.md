## <a id="5"></a>#5 🟡 테스트 application.yml 교체 (doll_gacha → 이 프로젝트)

- 파일: `spring_ssr_security/src/test/resources/application.yml`
- 문제: 내용이 무관한 **doll_gacha** 프로젝트 것. `data-dollshop.sql`·`data-files.sql`·
  `data-review.sql`(이 프로젝트에 없음) 참조 + kakao OAuth2 + JWT 설정 → `contextLoads()`
  가 SQL 초기화 실패로 깨질 가능성.
- 조치: 이 프로젝트에 맞는 최소 설정으로 교체.
  - datasource: main과 동일한 `test` DB (MariaDB)
  - `ddl-auto: create-drop`, `defer-datasource-initialization: true`
  - `data-locations: classpath:data-users.sql` **하나만** (실제 존재하는 파일)
  - oauth2 / jwt / doll_gacha 관련 전부 제거
- 사이드 이펙트: 테스트 실행에는 로컬 MariaDB(`test`) 필요 (main과 동일 전제).

## <a id="6"></a>#6 🟡 index.html 죽은 링크 / 없는 기능 카드 수정

- 파일: `spring_ssr_security/src/main/resources/templates/index.html`
- 문제: `/community`, `/api/test` → 404(Whitelabel). 기능 카드가 게시판·파일업로드·QueryDSL 등
  **이 프로젝트에 없는 기능**을 소개 → 초보자 혼란.
- 조치:
  - 헤더 네비: `커뮤니티`(/community), `API 테스트`(/api/test) 제거 →
    실제 존재하는 `마이페이지`(/mypage), `관리자`(/admin)로 교체. 로고도 "Security Demo".
  - Hero: 제목/부제/CTA를 세션 로그인 데모에 맞게 변경. CTA `커뮤니티 바로가기`(/community) →
    `로그인 하러 가기`(/login).
  - 기능 카드 4개를 실제 기능으로 교체: 세션 로그인/로그아웃, BCrypt 비밀번호,
    권한별 접근제어(hasAuthority), Thymeleaf+Security(sec:authorize / @AuthenticationPrincipal).
- 범위 주의: 검수 #6의 나머지(QueryDSL/파일업로드/api키/@EnableScheduling 등 잔재)는
  **보류**. 사유는 `00_작업요약.md`의 "보류 사유" 참고.

## <a id="7-2"></a>#7-2 ⚪ getAuthorities 람다 → SimpleGrantedAuthority

- 파일: `spring_ssr_security/src/main/java/com/ch/basic/user/CustomUserAccount.java`
  (+ 문서 `docs/spring_ssr_security/security설명.md` 코드블록/주석도 동일하게 반영)
- 동작은 `() -> role` 람다도 정상이지만, 초보자 강의에서는 관례적 구현체
  `new SimpleGrantedAuthority(role)`가 더 명확.
- 조치:

```diff
+ import org.springframework.security.core.authority.SimpleGrantedAuthority;
  ...
  for (String role : sessionUser.getRoles()) {
-     collection.add(() -> role);
+     // 문자열 권한("USER", "ADMIN")을 GrantedAuthority로 변환
+     // SimpleGrantedAuthority: Security가 제공하는 관례적 구현체 (람다 () -> role 로도 가능)
+     collection.add(new SimpleGrantedAuthority(role));
  }
```

- 검증: 이 환경에 JDK가 없어 컴파일은 못 돌림. `SimpleGrantedAuthority`는 Security 코어
  표준 클래스라 import/사용 정확. 로컬/다음 세션에서 `./gradlew compileJava` 1회 권장.

## <a id="7-3"></a>#7-3 ⚪ 회원가입 이메일 빈 문자열 → mypage 표시 보정

- 파일: `spring_ssr_security/src/main/resources/templates/mypage.html`
- 문제: 회원가입 시 email 미입력이면 빈 문자열 `""`이 저장되어(null 아님) mypage에서
  "설정되지 않음" 대신 빈칸이 보임.
- 조치: null 뿐 아니라 빈 문자열도 미설정으로 처리.

```diff
- th:classappend="${user.email == null} ? 'empty'"
- th:text="${user.email != null ? user.email : '설정되지 않음'}"
+ th:classappend="${#strings.isEmpty(user.email)} ? 'empty'"
+ th:text="${!#strings.isEmpty(user.email) ? user.email : '설정되지 않음'}"
```
