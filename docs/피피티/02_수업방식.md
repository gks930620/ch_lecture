## 수업 4단계

<div style="height: 2px; background: #ef4444; margin: 10px 0 16px;"></div>

<table>
  <tr>
    <td style="width: 25%; background: #eff6ff; color: #111827; border: 1px solid #bfdbfe;">
      <p style="margin: 0;"><strong style="color: #1d4ed8;">① 핵심 개념 설명</strong></p>
      <p style="margin: 8px 0 0; font-size: 15px;">암기용 이론이 아니라 "왜 이렇게 하는지"를 그림과 흐름으로 설명합니다. (강의자료 사이트 문서 기반)</p>
    </td>
    <td style="width: 25%; background: #f0fdf4; color: #111827; border: 1px solid #bbf7d0;">
      <p style="margin: 0;"><strong style="color: #16a34a;">② 바로 같이 구현</strong></p>
      <p style="margin: 8px 0 0; font-size: 15px;">배운 그 시간에 직접 코드로 만들어 봅니다. 막히는 지점은 그 자리에서 해결합니다.</p>
    </td>
    <td style="width: 25%; background: #fffbeb; color: #111827; border: 1px solid #fde68a;">
      <p style="margin: 0;"><strong style="color: #d97706;">③ 코드 리뷰·피드백</strong></p>
      <p style="margin: 8px 0 0; font-size: 15px;">작성한 코드를 함께 리뷰하고, 더 나은 구조로 개선하는 실무식 습관을 만듭니다.</p>
    </td>
    <td style="width: 25%; background: #fff1f2; color: #111827; border: 1px solid #fecdd3;">
      <p style="margin: 0;"><strong style="color: #e11d48;">④ 과제 → 결과물</strong></p>
      <p style="margin: 8px 0 0; font-size: 15px;">스스로 적용하는 과제로 마무리 — 회차마다 눈에 보이는 결과물이 남습니다.</p>
    </td>
  </tr>
</table>

## 수업 시간 밖에서도, 이렇게 돕습니다

<table>
  <tr>
    <td style="width: 33%; background:#f8fafc; color:#111827; border: 1px solid #e5e7eb;">
      <p style="margin: 0;"><strong style="color: #1d4ed8;">강의자료 사이트 제공</strong></p>
      <p style="margin: 8px 0 0; font-size: 15px;">모든 개념 문서·예제·문제/답안을 웹으로 공개 — 지금 보고 계신 이 사이트입니다. 언제든 다시 찾아보며 복습하세요.</p>
    </td>
    <td style="width: 33%; background:#f8fafc; color:#111827; border: 1px solid #e5e7eb;">
      <p style="margin: 0;"><strong style="color: #16a34a;">시간 외 질문 지원</strong></p>
      <p style="margin: 8px 0 0; font-size: 15px;">혼자 실습하다 막히면 질문하세요. 가능한 한 빠르게(보통 2시간 이내) 피드백합니다.</p>
    </td>
    <td style="width: 33%; background:#f8fafc; color:#111827; border: 1px solid #e5e7eb;">
      <p style="margin: 0;"><strong style="color: #e11d48;">AI 코딩 도구 활용법</strong></p>
      <p style="margin: 8px 0 0; font-size: 15px;">AI를 "베끼는 도구"가 아니라 "생산성 도구"로 쓰는 실무 노하우까지 함께 전달합니다.</p>
    </td>
  </tr>
</table>
