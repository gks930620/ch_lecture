## 강사 소개

<div style="height: 2px; background: #ef4444; margin: 10px 0 16px;"></div>

<div style="padding: 18px; border-radius: 12px; background: #ffffff; border: 1px solid #d1d5db; color: #111827;">
  <ul>
    <li><strong>현직 시스템 개발자</strong> — 실무 시스템 개발·운영 중, 현장에서 쓰는 방식 그대로 지도</li>
    <li><strong>웹개발 강의 경력 약 4년, 수강생 약 500명</strong> — 부트캠프(K-Digital Training)에서 입문자를 프로젝트 완성까지</li>
    <li><strong>입문자 눈높이 전문</strong> — 비전공자가 어디서 막히는지 알고, 그 지점부터 풀어줍니다</li>
    <li><strong>Java부터 배포까지 통합 지도</strong> — 파트별 강사가 아니라, 전체 흐름을 한 명이 끝까지 책임집니다</li>
  </ul>
</div>

## 부담 없는 수강 운영

<table>
  <tr>
    <td style="width: 50%; background:#f8fafc; color:#111827; border: 1px solid #e5e7eb;">
      <ul>
        <li><strong>선입금 없이 회차별 진행</strong> — 긴 계약 부담 없이 시작, 중단/재개 협의 가능</li>
        <li><strong>내 목표에 맞춘 커리큘럼</strong> — 취업 / 외주 / 내 서비스 만들기, 목표별 진도 설계</li>
      </ul>
    </td>
    <td style="width: 50%; background:#f8fafc; color:#111827; border: 1px solid #e5e7eb;">
      <ul>
        <li><strong>필요한 파트만 선택 수강</strong> — 예: Spring Security 집중, JWT 집중, 배포 집중</li>
        <li><strong>주 1~2회, 시간 협의</strong> — 직장인/학생 일정에 맞춰 유연하게 진행</li>
      </ul>
    </td>
  </tr>
</table>

## 이런 분께 추천합니다

<table>
  <tr>
    <td style="width:50%; background:#f8fafc; color:#111827; border: 1px solid #e5e7eb;">

        <li>취업용 포트폴리오를 실전 수준으로 만들고 싶은 분</li>
