## 혹시, 이런 고민 있지 않나요?

<div style="height: 2px; background: #ef4444; margin: 10px 0 16px;"></div>

<table>
  <tr>
    <td style="width: 50%; background: #f1f5f9; color: #475569; border: 1px solid #e5e7eb;">
      <p style="margin: 0;"><strong>혼자 공부할 때</strong></p>
      <ul>
        <li>"강의는 다 들었는데, 혼자서는 아무것도 못 만들겠어요"</li>
        <li>"에러 하나에 몇 시간씩 막히고, 물어볼 사람이 없어요"</li>
        <li>"뭘, 어떤 순서로 배워야 취업/외주까지 가는지 모르겠어요"</li>
        <li>"공부한 지 몇 달인데 보여줄 결과물이 하나도 없어요"</li>
      </ul>
    </td>
    <td style="width: 50%; background: #fef2f2; color: #111827; border: 1px solid #fca5a5;">
      <p style="margin: 0;"><strong style="color: #b91c1c;">이 수업에서는</strong></p>
      <ul>
        <li>개념 설명 후, 수업 중에 <strong>직접 같이 구현</strong>하며 완성합니다</li>
        <li>막히면 바로 해결 + 수업 외 질문도 <strong>빠르게 피드백</strong>합니다</li>
        <li>기초 → 실전 → 배포로 이어지는 <strong>검증된 12단계 로드맵</strong>을 따라갑니다</li>
        <li>매 회차 결과물이 쌓여 <strong>그대로 포트폴리오</strong>가 됩니다</li>
      </ul>
    </td>
  </tr>
</table>
