# ch1_DB와SQL시작하기

---

## 학습 목표
- 데이터베이스(DB)가 왜 필요한지 설명할 수 있다.
- 테이블 / 행 / 열 / 기본키가 무엇인지 안다.
- SQL 이 무엇이고, DDL / DML / TCL 이 어떻게 나뉘는지 안다.
- 실습용 테이블 스크립트를 실행해서 실습 환경을 준비한다.

> 오라클 설치, 사용자(계정) 생성, 접속(connect)은 이미 끝났다고 가정한다.  
> 이 강의는 접속한 다음부터, 즉 **SQL을 작성하는 것부터** 시작한다.

---

## 1. 데이터베이스가 왜 필요한가

프로그램은 결국 **데이터를 다루는 일**이 대부분이다.  
회원가입 하면 회원 정보를 저장해야 하고, 쇼핑몰이면 상품과 주문 내역을 저장해야 한다.

메모장이나 엑셀 파일에 저장하면 안 될까? 데이터가 많아지면 문제가 생긴다.

- 수백만 건에서 원하는 데이터를 **빨리 찾기** 어렵다.
- 여러 명이 **동시에** 읽고 쓰면 파일이 깨진다.
- 프로그램이 죽었을 때 **저장하던 데이터가 어중간하게** 남을 수 있다.

이런 문제를 전부 해결해 주는 전문 프로그램이 **DBMS**(DataBase Management System)다.  
오라클(Oracle)은 전 세계에서 가장 많이 쓰이는 상용 DBMS 중 하나이고, 국내 기업 프로젝트에서 특히 많이 쓴다.

> DB = 데이터 저장소 그 자체, DBMS = 그 저장소를 관리해 주는 프로그램.  
> 실무에서는 구분 없이 그냥 "DB"라고 부르는 경우가 많다.

---

## 2. 테이블 — 데이터를 담는 표

관계형 데이터베이스(RDB)는 모든 데이터를 **표(테이블)** 형태로 저장한다.  
엑셀 시트를 떠올리면 된다.

사원 테이블(EMP) 예시:

| EMP_ID | EMP_NAME | JOB | SALARY | DEPT_ID |
|--------|----------|------|--------|---------|
| 1001 | 김철수 | 사장 | 9000 | 10 |
| 1002 | 이영희 | 부장 | 6500 | 20 |
| 1003 | 박민수 | 과장 | 5200 | 20 |

용어를 정확히 알아두자. 앞으로 계속 쓴다.

| 용어 | 다른 이름 | 의미 |
|------|-----------|------|
| 테이블(table) | 릴레이션 | 데이터를 담는 표 하나 |
| 행(row) | 레코드, 튜플 | 가로 한 줄. 데이터 1건 (사원 1명) |
| 열(column) | 컬럼, 필드 | 세로 한 줄. 데이터의 속성 (이름, 월급 …) |
| 기본키(primary key, PK) | | 행 하나를 유일하게 구분하는 컬럼 (사원번호) |

**기본키**가 중요하다. 이름은 동명이인이 있을 수 있지만, 사원번호는 절대 겹치지 않는다.  
"1002번 사원의 월급을 올려라"처럼, 특정 행을 정확히 지목할 때 기본키를 쓴다.

## 3. SQL — 데이터베이스에게 말 거는 언어

SQL(Structured Query Language)은 DBMS에게 일을 시키는 언어다.  
"사원 테이블에서 월급 5000 이상인 사람을 보여줘"를 SQL로 쓰면:

```sql
SELECT * FROM EMP WHERE SALARY >= 5000;
```

Java 같은 프로그래밍 언어와 다르게, SQL은 **"어떻게"가 아니라 "무엇을"** 만 쓴다.  
어떻게 찾을지는 DBMS가 알아서 한다.

### 3.1 SQL의 종류

SQL 문장은 하는 일에 따라 세 갈래로 나뉜다. 이 강의의 목차이기도 하다.

| 분류 | 뜻 | 명령어 | 하는 일 |
|------|----|--------|---------|
| **DDL** | Data Definition Language (정의) | CREATE, ALTER, DROP, TRUNCATE | 테이블 같은 구조를 만들고/바꾸고/없앤다 |
| **DML** | Data Manipulation Language (조작) | INSERT, UPDATE, DELETE, SELECT | 테이블 안의 데이터를 넣고/고치고/지우고/조회한다 |
| **TCL** | Transaction Control Language (트랜잭션 제어) | COMMIT, ROLLBACK, SAVEPOINT | 변경을 확정하거나 되돌린다 |

> DCL(GRANT/REVOKE, 권한 제어)도 있지만 계정 관리자가 주로 쓰므로 이 강의에서는 다루지 않는다.

### 3.2 SQL 작성 규칙

- SQL 은 **대소문자를 구분하지 않는다**. `select` = `SELECT`. (단, 데이터 값 `'김철수'` 는 대소문자를 구분한다)
- 문장 끝에 세미콜론 `;` 을 붙인다.
- 주석: `--` 뒤는 그 줄 끝까지 주석, `/* */` 는 여러 줄 주석.

```sql
-- 한 줄 주석
SELECT * FROM EMP;   /* 여러 줄
                        주석 */
```

관례상 **명령어는 대문자, 줄바꿈으로 절을 구분**해서 쓰는 경우가 많다. 이 강의도 그렇게 쓴다.

## 4. 실습 환경 준비

### 4.1 실습 도구

- **SQL Developer** (오라클 공식 무료 GUI 도구) 사용을 권장한다.
  - 워크시트에 SQL 을 쓰고, 커서를 문장에 두고 `Ctrl + Enter` → 그 문장 하나 실행
  - `F5` → 워크시트 전체를 스크립트로 실행
- SQL*Plus(명령창)로 해도 상관없다. SQL 자체는 완전히 동일하다.

### 4.2 실습 테이블 만들기

강의 전체에서 사용할 실습 테이블 4개를 먼저 만들어 둔다.

1. [실습테이블.sql](실습테이블.sql) 파일을 연다.
2. 내용 전체를 SQL Developer 워크시트에 붙여넣고 `F5`(스크립트 실행)를 누른다.
3. 처음 실행하면 앞부분 `DROP TABLE` 에서 "table or view does not exist" 오류가 4번 나오는데 **정상이다**. (지울 테이블이 아직 없어서 나는 오류)
4. 마지막 SELECT 결과로 데이터가 보이면 성공.

만들어지는 테이블:

| 테이블 | 내용 | 건수 |
|--------|------|------|
| DEPT | 부서 (부서번호, 부서명, 지역) | 4 |
| EMP | 사원 (사원번호, 이름, 직급, 상사, 입사일, 월급, 보너스, 이메일, 부서번호) | 12 |
| PRODUCT | 상품 (상품번호, 상품명, 분류, 가격) | 6 |
| ORDERS | 주문 (주문번호, 상품, 담당사원, 고객, 수량, 주문일) | 10 |

스크립트 안의 CREATE TABLE, INSERT 문법은 ch2, ch3 에서 배운다. 지금은 이해 못 해도 된다.

### 4.3 잘 만들어졌는지 확인

```sql
SELECT * FROM EMP;
```

`SELECT * FROM 테이블` 은 "그 테이블의 모든 데이터를 보여줘"라는 뜻이다.  
사원 12명이 보이면 준비 끝. SELECT 문법은 ch4 에서 자세히 배운다.

```sql
-- 내 계정에 있는 테이블 목록 확인
SELECT TABLE_NAME FROM USER_TABLES;
```

## 정리

- DBMS 는 많은 데이터를 안전하게 저장/검색/공유하게 해 주는 프로그램이고, 오라클은 대표적인 DBMS 다.
- 관계형 DB 는 데이터를 **테이블(표)** 로 저장하고, 행 하나가 데이터 1건이다. **기본키**로 행을 구분한다.
- SQL 은 DDL(구조 정의) / DML(데이터 조작) / TCL(확정·취소) 로 나뉜다.
