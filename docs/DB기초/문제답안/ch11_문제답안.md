# ch11 문제답안

[← ch11 문서로](../ch11_윈도우함수.md)

## 1. 월급 순위

```sql
SELECT EMP_NAME,
       SALARY,
       RANK() OVER (ORDER BY SALARY DESC) AS 순위
FROM   EMP;
```

김철수(9000) 1위 → 이영희(6500) 2위 → 한가인(6200) 3위 → … → 신동엽(2400) 12위.

## 2. 부서별 입사 순번

```sql
SELECT DEPT_ID,
       EMP_NAME,
       HIRE_DATE,
       ROW_NUMBER() OVER (PARTITION BY DEPT_ID ORDER BY HIRE_DATE) AS 입사순번
FROM   EMP;
```

부서마다 1부터 다시 센다. 예: 10번 부서는 김철수(2015) 1, 유재석(2018) 2, 강호동(2022) 3.

## 3. 부서별 최고 월급자

```sql
SELECT DEPT_ID, EMP_NAME, SALARY
FROM   (SELECT DEPT_ID, EMP_NAME, SALARY,
               ROW_NUMBER() OVER (PARTITION BY DEPT_ID ORDER BY SALARY DESC) AS RN
        FROM   EMP)
WHERE  RN = 1;
```

결과: 10번 김철수, 20번 이영희, 30번 한가인, 그리고 **NULL 부서의 신동엽**.

ch8 의 서브쿼리 풀이와 달리 신동엽이 나온다 — `PARTITION BY` 는 NULL 도 하나의 파티션으로 묶기 때문이다. NULL 부서를 빼고 싶으면 `WHERE DEPT_ID IS NOT NULL` 을 추가한다.

## 4. 주문금액 누적합

```sql
SELECT O.ORDER_ID,
       O.ORDER_DATE,
       P.PRICE * O.QUANTITY                                  AS 주문금액,
       SUM(P.PRICE * O.QUANTITY) OVER (ORDER BY O.ORDER_DATE) AS 누적금액
FROM   ORDERS O
JOIN   PRODUCT P ON O.PRODUCT_ID = P.PRODUCT_ID
ORDER BY O.ORDER_DATE;
```

| 5002 | 700,000 | 2,200,000 |
| 5003 | 240,000 | 2,440,000 |

## 5. 직전 입사자와의 월급 차이

```sql
SELECT EMP_NAME,
       HIRE_DATE,
       SALARY,
       SALARY - LAG(SALARY) OVER (ORDER BY HIRE_DATE) AS 직전입사자와차이
FROM   EMP
ORDER BY HIRE_DATE;
```

첫 입사자(김철수)는 직전이 없어 NULL. 두 번째 이영희는 6500 − 9000 = −2500. …

## 6. 월급 TOP 5

```sql
-- FETCH FIRST (12c 이상)
SELECT EMP_NAME, SALARY
FROM   EMP
ORDER BY SALARY DESC
FETCH FIRST 5 ROWS ONLY;

-- ROWNUM 방식 (정렬을 인라인 뷰로 먼저!)
SELECT EMP_NAME, SALARY
FROM   (SELECT EMP_NAME, SALARY
        FROM   EMP
        ORDER BY SALARY DESC)
WHERE  ROWNUM <= 5;
```

결과 5명: 김철수(9000), 이영희(6500), 한가인(6200), 유재석(5500), 박민수(5200).

## 7. RANK / DENSE_RANK / ROW_NUMBER 비교

현재 데이터에서는 **셋 다 결과가 같다.** 12명의 월급이 전부 달라서 동점이 없기 때문이다.  
세 함수의 차이는 오직 **동점 처리**에서만 나타난다. 확인해 보고 싶다면 누군가의 월급을 다른 사람과 같게 UPDATE 한 뒤 다시 실행해 보자. (RANK 는 다음 순위를 건너뛰고, DENSE_RANK 는 안 건너뛰고, ROW_NUMBER 는 동점에도 서로 다른 번호를 준다)
