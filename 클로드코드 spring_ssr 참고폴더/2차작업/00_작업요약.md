## 필수 2건 — 처리 완료

### 1. [높음] WebConfig `/community/*` exclude가 글쓰기 로그인 체크 무력화 → **수정**

- **재검증 결과 사실**: `/community/*`(한 세그먼트)는 `/community/write`와 매칭되고, Spring `MappedInterceptor`는 exclude를 include보다 우선 평가 → `/community/write`에 인터셉터 미적용 → 비로그인 write 폼 접근 가능, POST 시 `loginUser.getId()` NPE(500)
- **조치**:
  - `WebConfig.java` — **exclude 목록 전체 제거** (include 4개가 명시적이라 exclude는 전부 no-op이었고, 그중 `/community/*`만 유해했음). 클래스 주석에 "exclude는 include보다 우선 평가" 교육 포인트 + 과거 버그 경위 기록
  - 문서 동기화 4곳: `개념_07`(4-1 인용 수정 + ⚠️ exclude 우선순위 교육 포인트 블록 추가), `개념_11`(5장 인용 수정 + 4장 각주를 "넓게 걸 때만 exclude 필요"로 정정 + 3장에 주의 문구), `프로젝트_구조_정리`(적용 범위 표 각주 갱신)
