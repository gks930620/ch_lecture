## 반드시 처리해야 할 항목 2건

### 1. [높음·신규] WebConfig의 `/community/*` exclude가 글쓰기 로그인 체크를 무력화 (검수자 직접 확인 완료)

- `WebConfig.java:68`의 `excludePathPatterns("/community/*")`는 상세 조회용이지만, Spring의 `MappedInterceptor`는 **exclude 패턴을 include보다 우선 평가**하며 한 세그먼트 패턴 `/community/*`는 `/community/write`에도 매칭됨.
- 결과: 비로그인 사용자가 `/community/write`에 접근해도 리다이렉트 없이 폼이 열리고, POST 시 `CommunityController.java:100`의 `loginUser.getId()`에서 **NPE → 500 에러**. (94행 주석 "Interceptor 통과 → null 아님 보장"이 실제로는 성립하지 않음. `/community/*/edit`, `/community/*/delete`는 두 세그먼트라 정상 차단.)
- 1차검수·1차작업 모두 놓친 기존 소스 버그이지만, 이번에 개념_07 4-1장이 이 설정을 "write는 Interceptor가 차단"이라고 **정상 동작으로 공식화**했으므로 이번 차수에서 소스+문서 동시 수정 필요.
- **수정 제안**: include 목록이 명시적 4개뿐이므로 exclude에서 최소 `/community/*` 제거 (사실상 exclude 전체가 불필요). 수정 후 개념_07:130-138의 WebConfig 인용도 동기화. "exclude가 include보다 우선"은 오히려 좋은 교육 포인트.

### 2. [중간·신규] 복원된 `com/aop/step1~3` 15개 파일이 git에 커밋되지 않음

- 워킹트리는 완벽(컴파일·실행 재현 확인)하나 `git ls-files -s` 결과 인덱스에는 여전히 빈 blob(`e69de29`). 지금 `git checkout -- .`이나 신규 clone이 일어나면 **다시 0바이트로 돌아감**.
- **수정 제안**: 다른 1차작업 변경분과 함께 `git add` 후 커밋.
