# 2차 검수: 신규 발견 사항 (높음 1 / 중간 1 / 낮음 10)

## 필수 처리

### 1. [높음] WebConfig `/community/*` exclude가 글쓰기 로그인 체크를 무력화 (검수자 직접 확인)

- **위치**: `spring_ssr/src/main/java/com/ch/basic/common/config/WebConfig.java:68` + `docs/spring_ssr/개념_07_Session_Login.md:130-138`
- **문제**: Spring의 `MappedInterceptor`는 exclude 패턴을 include보다 **우선 평가**하고, 한 세그먼트 패턴 `/community/*`(상세 조회용)는 `/community/write`에도 매칭됨. 따라서 addPathPatterns에 `/community/write`를 넣었어도 인터셉터가 실행되지 않음.
- **실제 영향**: 비로그인 사용자가 `/community/write` 접근 시 리다이렉트 없이 폼이 열리고, POST 시 `CommunityController.java:100`의 `loginUser.getId()`에서 **NPE → 500 에러**. 94행 주석 "Interceptor 통과 → null 아님 보장"이 성립하지 않음. (`/community/*/edit`, `/community/*/delete`는 두 세그먼트라 `/community/*`에 안 걸려 정상 차단, `/mypage` 정상.)
- **경위**: 1차검수·1차작업 모두 놓친 기존 소스 버그. 다만 이번에 개념_07 4-1장이 이 설정을 "write는 Interceptor가 차단"이라고 정상 동작처럼 공식화했으므로 이번 차수에서 처리 필요.
- **수정 제안**: include 목록이 명시적 4개(`/community/write`, `/community/*/edit`, `/community/*/delete`, `/mypage`)뿐이므로 exclude 목록은 사실상 전부 불필요 — 최소한 `/community/*` 제거. 수정 후 개념_07 4-1의 WebConfig 인용 동기화. "exclude가 include보다 우선한다"는 사실 자체를 교육 포인트로 문서에 추가하면 재발 방지에도 좋음.

### 2. [중간] 복원된 `com/aop/step1~3` 15개 파일이 git에 커밋되지 않음

- **위치**: `spring_ssr/src/main/java/com/aop/step1~step3` (15개 파일)
- **문제**: 워킹트리 복원본은 완벽(javac 컴파일·Main 3개 실행·gradlew 전체 컴파일 전부 재현 확인)하나, `git ls-files -s` 결과 인덱스에는 여전히 빈 blob(`e69de29`). `git checkout -- .`이나 신규 clone 시 **다시 0바이트로 회귀**.
- **수정 제안**: 다른 1차작업 변경분과 함께 `git add` 후 커밋. (1차검수 수정 제안이 "복원·커밋"이었으므로 절반만 이행된 상태.)

## 낮음 (선택 반영)

### 수정 과정에서 파생된 어색함 4건

3. **개념_11_Filter_Interceptor.md:114-127** — 3장 예시 클래스를 `MyInterceptor`로 바꿨는데 바로 아래 "Interceptor 등록" 예시는 여전히 `LoginCheckInterceptor`를 등록. 등록 예시도 `myInterceptor`로 통일하거나 "실제 등록 코드는 5장 참고" 한 줄 추가.
4. **SPRING_SSR_정리.md:84-86** — 소제목 "📌 남아있는 미작성 항목" 아래 본문이 "모든 개념 문서 작성 완료." — 모순은 해소됐으나 제목-본문이 어긋남. 소제목을 "📌 문서 작성 현황" 등으로 변경.
5. **개념_03_JPA_Entity.md:302 vs 343** — "단순화 버전에서 keyword.trim() 생략"이라 안내했는데 아래 코드의 null 체크에는 `keyword.trim().isEmpty()`가 그대로 있음. 실제 생략된 것은 "검색 조건에 trim된 키워드를 사용하는 부분"(CommunityRepositoryImpl.java:122) — 문구 정밀화.
6. **개념_10_AOP.md:374** — "(단, Spring Boot **웹 애플리케이션**의 기본 설정은 CGLIB)"의 "웹" 한정이 부정확 — Boot의 `proxy-target-class=true` 기본값은 웹 여부와 무관하게 적용됨. "Spring Boot(자동 설정 사용 시)의 기본값은 CGLIB"로 다듬기. ※ 1차검수 제안 문구를 그대로 따른 것으로 작업자 귀책 아님.

### 스니펫 완결성 2건

### 1차검수 범위 밖 잔여 4건
