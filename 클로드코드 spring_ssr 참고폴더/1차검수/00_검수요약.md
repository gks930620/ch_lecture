## 반복 발견되는 패턴 (전체 문서 공통)

1. **"실제 코드"라고 표기했는데 실제 소스와 다른 예제가 많음** — 단순화 자체는 교육상 괜찮으나, "실제 코드" 라벨 때문에 코드와 대조하는 수강생이 혼란. "단순화한 버전" 표기를 하거나 실제 코드로 교체 필요. (JPA 검색 코드, Validation DTO 메시지, Interceptor 세션 캐스팅 타입, MVC 컨트롤러 시그니처 등 10건 이상)
2. **작성자 초안 메모/혼잣말이 배포 문서에 잔존** — 개념_06(전파는 빼자..), 개념_00 목차(~해야겠군), CORS 문서(나만 이해한거 같아..), 프로젝트_구조(어려운거 아니니까..), 테스트코드(굳이??) 등. 배포 전 일괄 제거 필요.
3. **미구현 기능이 구현된 것처럼 서술** — supabase 파일 처리(프로젝트_구조), FileUtil 클래스(파일테이블설계), MockMvc 테스트(테스트코드) 등은 소스에 존재하지 않음.
4. **개념_04, 개념_05 번호가 설명 없이 비어 있음** — 목차에서 03 → 06으로 건너뜀. 재번호 부여 또는 각주 필요.

## 잘 되어 있는 부분

- 스케줄러 문서: cron 표현식 해석 전수 계산 검증 결과 **전부 정확**, fixedRate/fixedDelay 구분 정확
- IoC step1~4 코드 자체는 문서와 정확히 일치, MVC 요청 흐름/PRG 패턴 설명 정확
- 트랜잭션 롤백 규칙(RuntimeException만 기본 롤백), 자기호출 문제, readOnly 설명 정확
- 세션 로그인 흐름·세션 키 `"loginUser"` 일관성, LoginUserDTO 설계 설명 정확
- AOP step4 코드·포인트컷 해석 정확, CORS 프록시 우회 원리 설명 정확
- 프로젝트_구조 문서의 URL 표·클래스 목록 대부분 실제와 일치
- 민감정보: `.env`의 실제 API 키는 git 미추적 + 문서 미노출 (관리 상태 양호)
